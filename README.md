# 批量翻译工具（中文 → 俄语 / 西语 / 葡语 / 英语）

免费的批量翻译软件，支持图片和视频，Windows 单文件 exe 双击即用。

## 功能

| 功能 | 说明 |
|---|---|
| 批量导入 | 选择一个文件夹，自动扫描其中所有图片（jpg/png/webp/bmp）和视频（mp4/mov/mkv/avi/webm） |
| 按语言导出 | 在导出目录下按语言生成子文件夹：`俄语/`、`西语/`、`葡语/`、`英语/` |
| 图片翻译 | OCR 识别 → 翻译 → 智能抹除原文（纯色/渐变/复杂背景自适应）→ 按原排版回填译文 |
| 排版美化 | 自动估计粗体、继承原描边色、均衡断行（杜绝单词孤行）、短句优先单行、上下邻框避让 |
| 视频翻译 | 语音识别时间轴 → 翻译 → AI 配音替换人声（保留背景音乐），字幕文件单独导出 |
| 画面文字替换 | 逐帧识别视频内中文标题/角标/硬字幕，原位抹除并替换为译文（可选，较慢） |
| 自然配音 | 自适应最慢语速（能慢则慢）、自动裁剪空边、句间零重叠、背景音响度自校准 |
| 完全免费 | 翻译走免费云端接口（Google / 腾讯 TranSmart 自动切换），AI 模型全部本地运行 |

## 使用（成品 exe）

1. 双击 `批量翻译工具.exe`
2. 选择导入文件夹（含图片/视频），导出文件夹默认 `<导入>/翻译输出`
3. 勾选目标语言，点击「开始翻译」
4. 首次运行会自动下载 AI 模型（语音识别约 500MB，人声分离约 80MB，仅下载一次）

## 从源码打包（Windows）

```
双击 build.bat
```

需要预先安装 Python 3.10–3.12（安装时勾选 Add to PATH）。脚本自动创建虚拟环境、
安装依赖（约 1-2GB）、用 PyInstaller 打包出 `dist\批量翻译工具.exe`。

## 从源码运行

```bash
pip install -r requirements.txt
python gui.py          # 图形界面
python cli.py 输入文件夹 输出文件夹 ru es pt en   # 命令行（可选）
```

## 说明

- 视频配音文稿长度受原语音时长约束：信息密度高的视频，个别短句语速会偏快，
  软件会自动选择"能放进时间窗的最慢一档"，并保证句间不重叠。
- 逐帧画面文字替换耗时较长（约每 30 秒视频 10-20 分钟，CPU），可按需关闭。

## 技术栈

- 翻译：Google 免费接口 → 腾讯 TranSmart → 本地 NLLB-200（自动降级）
- OCR：RapidOCR（ONNX，本地）
- 语音识别：faster-whisper（本地，ModelScope 下载）
- 配音：edge-tts（免费自然音色，自适应语速）
- 人声分离：Demucs htdemucs（本地 CPU）
- 视频合成：ffmpeg（无系统 ffmpeg 时自动使用内置 static-ffmpeg）
