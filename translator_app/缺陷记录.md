## 历史缺陷（v1.0–v1.5 已修）

- 图3黑块：OCR 框漏字 + 渲染溢出 → OCR 框扩展(+35%w/+45%h) + 单行宽度钳制 + 边框锁定渲染
- 图3边框被误抹 → 笔画抹除时大而稀疏连通域判定为装饰边框保留
- 图4彩色标签被抹除 → 标签检测（HSV饱和度）+ 标签内笔画抹除 + 渲染锁定标签内部
- 图5横幅误走笔画抹除 → 背景均匀度门控（uni≥0.5 才允许笔画抹除）
- 抹除矩形接缝 → 掩膜膨胀13+高斯羽化 σ=8 融合
- CI 冒烟误判：画面文字原位替换时不生成 .srt → 冒烟测试改为可选检查
- CI 打包失败：PowerShell 不支持 cmd 的 `^` 续行 → 改反引号

## 2026-08-31 v1.7 新图（收纳七件套）修复
- **LaMa 尺寸对齐回退**：SimpleLama 内部把输入对齐到 8 的倍数（790×1477→792×1480），输出尺寸与 mask 不一致导致羽化融合广播失败，静默回退旧算法把整框（含棕色标签）抹掉 → 两次 LaMa 调用后都裁剪 `out = out[:h, :w]`，且回退路径必须告警日志
- **混色误判极性**：深字+白色光晕/图标混合时 `_estimate_colors` p75 估计落在中间灰甚至 217~233，Otsu 选错极性只罩住几百像素 → 防混色守卫改为 `90 < lum < 250 且背景不更暗` 时用 p95 差异簇重估，浅底（bl>200）下明显更暗即采纳
- **笔画 mask 用膨胀框重估颜色**：`_stroke_mask` 在膨胀 10px 的框内重估前景色，框上图标/邻行文字混入导致极性翻转（fl 52→218），mask 几乎为空 → `_stroke_mask` 增加 `fg` 参数，一律传入未膨胀框的估计色
- **二次抹除不稳定**：二抹在修复结果上重做 Otsu 笔画提取，近均匀浅底上阈值漂移，是否触发整框回退近乎随机（单框干净、14 框联跑残影） → 二抹改为直接与背景色比亮度（深字找暗于 bg-25、白字找亮于 bg+25），并滤掉触及区域外缘的连通块防误伤图标
- **文字旁图标被糊化**：①笔画 mask 把膨胀区内卷入的图标笔画当文字抹掉 → 连通块质心落在未膨胀框外的一律保留；②焦外柔化（高斯模糊 σ5）在浅色均匀背景上把邻近图标糊成雾斑 → 仅在存在非均匀背景框（uni<0.5）时启用柔化
- **小标签译文缩得过小看不清**：彩色小标签强制单行+宽扁规则把字号压到 12px 以下 → 标签模式允许两行（字号至少提升 40%）、高度余量收紧到 1.06 保证不出标签、内缩从 8%/12% 减到 5%/6%
- **葡语斜杠联项误译**：GLM 批量译"鞋子/杂物"为"Sapatos/obrigado"（葡萄牙语"谢谢"）等串译 → 术语库固定三类斜杠联项标签精译
- **同排文字字号不一**：各框独立搜索字号，同排译文长短不同导致字号参差不齐 → 渲染改两遍：先探测各框可行字号，同一水平带（带高相近）分组取组内最小字号强制统一
- **长单词被拦腰截断**：断行器在单词超宽时按字符硬切（"Miscellaneo/us bag"） → 字号搜索跳过放不下最长单词的字号，选定后仍超宽则逐级缩小兜底

## 2026-08-31（双肩包图测试，v1.7 续）

- **跨栏清单误合并**：`merge_line_boxes` 按 (cy,x) 排序后同行相邻框水平间距为负，被当作同一行合并，3×3 清单翻译串栏（"杂志 15.6英寸电脑 钱包"挤成一行）。修复：水平闭合条件改为 `-2 <= gap < min_h*0.6`，负间距不允许合并。
- **低覆盖率颜色估计失效**：加宽框内文字占比 <25% 时 p75 分位取到背景色，fg=bg=255，极性判成白字导致笔画 mask 全空、文字完全没抹。修复：`_estimate_colors` 低覆盖守卫——`max(fg)-min(fg)<=30 且 |fg-bg|max<=30` 时改用距离分布 p95 重估。
- **浅底羽化环残影**：LaMa 填充与浅色底有轻微色差，羽化环把原文字边缘混回结果，留下雾状鬼影。修复：均匀浅底（uni≥0.65 且底色亮度>200）登记平涂清单，混合后在膨胀 25px 核心区内强制贴回底色。
- **整批译错语种**：GLM 偶发把俄语请求答成英语（整批）。修复：`_lang_suspect` 按目标语文字区间校验（西里尔/阿拉伯/泰/印地/希伯来/韩/日等），批量与单条兜底链路命中即抛错重试。
- **标签小数点/数字误抹**：`_label_stroke_mask` 吃掉 15.6 的小数点，且 11px 膨胀晕染到上方数字。修复：跳过质心位于文字行上方的连通域、保护圆点状小组件、膨胀核降为 7、裁剪 inner 顶边以上 15px 的行范围。
